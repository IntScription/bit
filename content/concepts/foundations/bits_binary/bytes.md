# Bytes

Eight switches, grouped together and treated as one unit, make a byte.

```
128  64  32  16  8  4  2  1
```

The same eight-switch demo you used for [[binary]] — a byte *is* that
demo, just given a name. With 8 bits, you can represent `2^8 = 256`
distinct values: 0 through 255.

Group enough bytes together and you get everything a computer stores: a
number, a character, a pixel, a sound sample. The byte is the unit
memory is measured and addressed in.

## Real world

- Memory addressing granularity
- File sizes — a kilobyte, megabyte, gigabyte are all just byte counts
- Character encoding (ASCII assigns one byte per character)
