# Binary

Eight bits, each worth twice its neighbor:

```
128  64  32  16  8  4  2  1
```

Turn a switch on and its value counts toward the total. Turn on the 8
switch, the 2 switch, and the 1 switch:

```
  0   0   0   0  1  0  1  1
                8     2  1
```

`8 + 2 + 1 = 11`

That's binary: a number written entirely in on/off switches instead of
the ten digits you already know.
