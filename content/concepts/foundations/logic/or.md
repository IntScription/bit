# OR

Two switches feed into an OR gate. The output turns on if **either**
input — or both — are on.

```
0 OR 0 = 0
0 OR 1 = 1
1 OR 0 = 1
1 OR 1 = 1
```

OR is the generous operator: it only takes one input agreeing to flip the
output on.

## Real world

- Permission checks where any single condition is enough ("admin OR owner")
- Bitmasking to set specific bits (OR with 1 forces a bit on)
- Hardware OR gates in digital circuits
