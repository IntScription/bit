# Boolean Logic

You already toggled switches on and off for [[bits]]. Boolean logic is
just giving those two states names people reason with instead of
numbers:

```
1  =  ON   =  true
0  =  OFF  =  false
```

Same thing, different label. Once a value is true or false, you can
combine it with other true/false values using logical operators —
[[and]], [[or]], [[xor]], [[not]] — to decide bigger true/false questions
from smaller ones. "Is the door locked AND the alarm armed?" is boolean
logic before it's ever a line of code.

Every `if` statement you'll ever write, and every logic gate etched into
a CPU, is this same idea underneath.

## Real world

- Conditional statements (`if` / `else`) in every programming language
- Digital circuit design — physical logic gates
- Search query logic — "AND"/"OR"/"NOT" filters
